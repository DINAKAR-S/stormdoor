stormdoor. admin

Do not know it? Run this where the gateway is running:

stormdoor admin-token

It prints the token and does not change between restarts. If you set STORMDOOR_ADMIN_TOKEN yourself, that is the one to use. Either way it is kept in this browser only and sent as a header, never in a URL.
